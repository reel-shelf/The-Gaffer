# The Gaffer

FC 26 Career Mode assistant manager: wonderkid scouting, season objectives, club notes and tips.

## Put it on GitHub Pages
1. Create a new repository called `the-gaffer`.
2. Upload everything in this folder (index.html, manifest.json, sw.js, README.md and the icons folder).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)` → Save.
4. Your app is live at `https://<your-username>.github.io/the-gaffer/`.

## Install it on your phone
Open the link in Chrome → menu (⋮) → "Add to Home screen" / "Install app".

## Play Store (later)
Paste your GitHub Pages link into pwabuilder.com → Package for Android. It builds the Android package to upload to Google Play Console.

## Switching on the AI assistant (free)
1. Go to https://aistudio.google.com/apikey and sign in with Google.
2. Tap "Create API key" and copy it.
3. In The Gaffer, paste it on the Assistant tab (or My Club → Assistant AI) and tap Save.

The assistant uses Gemini's free tier (daily limits apply). The key is saved on that phone only.
Scout, Objectives, My Club and Tips work offline; the assistant needs internet.
